# Dreamscape texture sources

`lroc-color-2k.jpg` is the unmodified 2048 × 1024 lunar color map from
[NASA's Scientific Visualization Studio — CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/).
Credit: NASA's Scientific Visualization Studio, Ernie Wright; Lunar
Reconnaissance Orbiter / LROC WAC color mosaic.

Downloaded 2026-09-23 from:
https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_2k.jpg

SHA-256: `f7130a1822681fa7512d7dcfd40db8c10b9ba4f06777910348698260ed7a2170`.

The shader projects this albedo onto a sphere and adds directional lighting
and atmospheric glow. It is bundled locally; there is no NASA request during
page playback. Cloud volumes, sky, mist and fireflies are procedural.
