# Typography test face

EB Garamond variable font, downloaded from the Google Fonts upstream repository:
https://github.com/google/fonts/blob/main/ofl/ebgaramond/EBGaramond%5Bwght%5D.ttf

Distributed under the SIL Open Font License 1.1, retained in EBGaramond-OFL.txt.
The face exercises real GSUB stylistic sets, figures, ligatures, small capitals,
fractions, ordinal/super/subscript forms, and alternate glyph discovery.
