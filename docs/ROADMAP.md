# Project status

omadesign is an alpha native Linux design studio. The current tools cover vector design, layout frames, raster painting, photo adjustments, and motion in a shared document.

The [manual](MANUAL.md) describes the available workflows. Known issues and planned work live in [GitHub Issues](https://github.com/michaelmonetized/omadesign/issues).

The current release is [v0.5.4](https://github.com/michaelmonetized/omadesign/releases/tag/v0.5.4). It adds chroma key, 17 raster filters and 13 effects, multi-stop linear/radial/shape/conic fill and stroke gradients, a shared alpha-capable color picker, per-object blending, and drag sorting/nesting. Layout includes responsive Stack/Wrap/Grid, document-local components, variants, variables and interactive prototypes. The 0.5.3 native clipboard fixes and explicit cloud project sharing/review remain included. See the [full release notes](blog/0.5.4-more-control-on-the-canvas.md) and [studio log](https://omadesign.app/updates).

Import supported layers from PSD/PSB, GIMP `.xcf`, PDF, PDF-compatible AI, SVG and OpenRaster, with an optional [Affinity bridge](affinity-import.md). Photo decodes supported camera RAW files at full resolution, saves adjustments in `.omaphoto` files and exports developed 16-bit PNG/TIFF or JPEG. See [file formats](format-support.md) for the import/export matrix and specific limits.

Current limitations include live vector-object masks, adjustable raster effect stacks, rich inline text, advanced publishing, simultaneous multi-user editing, PDF/X and CMYK print workflows. Raster treatments use Apply/Undo; existing layer masks are pixel masks. Layout components and variables stay document-local, Grid has uniform columns, and native Figma/Framer interchange is not supported. HTML exports are responsive design/prototype artifacts, not a CMS or application hosting service. Cloud provides versioned project transfer, flat snapshot review, member roles and explicit public publishing. Affinity interoperability is partial, with the new unified `.af` format awaiting verification against a real document. Native AI/Affinity writing is not available. RAW support varies by camera and compression; proprietary camera looks and automatic lens corrections are not reproduced, and placement in Design uses 8-bit pixels.
