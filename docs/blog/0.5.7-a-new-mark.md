# A new mark. A quicker look.

Omadesign 0.5.7 introduces the new official mark: the green circular emblem and
Omadesign wordmark, now used in the native welcome and About screens, the website
header and footer, and the product film. The supplied artwork keeps its colors
and geometry.

The product film returns near the end of the homepage with fresh native footage.
Its 32-second silent edit follows a 120 BPM grid, cutting on beats one and three
with movement between cuts. Play, pause, seek or replay it with the video controls.
The opening Cloud announcement remains available as before.

This release builds on 0.5.6's welcome screen, local document and brand-project
browsers, templates, and Omarchy agent handoffs. The branding update does not
change those editing workflows. [Cloud registration](https://omadesign.app/cloud)
and the [Omadesign Discord](https://discord.gg/ejkZS2RBx) remain available from
the website and welcome screen.

Install or update on ARM64 or x86_64 Linux:

```sh
curl -fsSL https://omadesign.app/install | sh
```

Existing documents, projects and preferences stay in place.
