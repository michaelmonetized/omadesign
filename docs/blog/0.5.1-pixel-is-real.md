# You can see the selection now

Pixel mode had a well full of tools. Brush worked. Clone mostly worked.
Zoom did what zoom does. Everything else was costume.

You would pick the marquee. Drag a box. Release. The box vanished. The
wand clicked and said nothing. Lasso drew a line that died on mouse up.
You could not tell if the tool was broken, unfinished, or waiting for a
modifier you had not found.

It was broken. The mask got written. Nothing drew it. Paint never asked
for it. So the studio pretended to select pixels and then went back to
painting the whole layer.

0.5.1 stops pretending.

Drag a rectangle. An ellipse. A lasso. Click the wand. The selection
stays. A tint sits on the pixels you picked. Ants walk the edge. Shift
adds. Esc clears. Delete punches a hole, and Undo puts the pixels back.

Then paint. The brush stays inside. Fill stays inside. Clone, heal,
smudge — inside. That is the whole point of a selection. It was missing.

Eyedropper had the same kind of lie. It sampled. It just would not show
you the color. The inspector now carries a chip. The Color row carries
the hex. You click, you see it.

Smudge used to stamp a disk every time the mouse twitched. It looks like
a smear now. Clone used to paste the same patch wherever you parked.
Alt-click a source, paint, and the offset travels with you.

The pointer used to wait. Six pixels of dead travel before a stroke or a
marquee believed you. Tools follow from the press. Placed images keep
their position, scale and rotation. Healing already knew how. The rest
of Pixel caught up.

This is still a young native Linux studio. The ants walk a box around
the selection; the tint is the real shape. Selections live in the
session, not the saved file. Layout is still frames, not Figma. Cloud is
still opt-in.

Install is one line. Home directory. ARM64 and x86_64.

```sh
curl -fsSL https://omadesign.app/install | sh
```

If `omadesign` is missing from PATH, run `~/.local/bin/omadesign`.
Relaunch. An open window is still yesterday's binary.
