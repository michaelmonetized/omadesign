# 0.5.0 — Layout, then show it

omadesign grew a fifth studio. **Layout.** Frames you can nest. Stacks that pack
a screen. Constraints that hold a button to the edge when the frame moves.
Mobile, landing, dashboard, card stack — four starters, all editable.

Cloud is optional. Sign in, turn sync on for one document, invite one person,
pin a note on a frame, resolve it. Nothing is public until you publish it.

The site lives at **https://omadesign.app**. The old GitHub Pages URL sends you
there. The showcase is a gallery with the door closed by default. The
competition is a waitlist and a rules page. Entries can wait. The hook is in.

Install stays the same curl line. ARM64 and x86_64. Home directory. MIT.

This is still a young native Linux studio. Layout is frames, stacks and
constraints — not Figma import. Sync is last-write-wins, not a CRDT. Clerk and
Convex are wired for when the keys land. The work is in the file.
