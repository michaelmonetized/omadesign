# Layout, then show it

omadesign grew a fifth studio. **Layout.** Frames you can nest. Stacks that pack
a screen. Constraints that hold a button to the edge when the frame moves.
Mobile, landing, dashboard, card stack — four starters, all editable.

You draw a frame with `F`. You drop a rectangle in it. You stack the children
and they pack with gap and padding. You pin a title to the top and it stays
there when the frame grows. That is a screen. Not a website. A screen you can
still open tomorrow.

Cloud is optional. Sign in, turn sync on for one document, invite one person,
pin a note on a frame, resolve it. Nothing is public until you publish it. The
showcase is a gallery with the door closed by default. The competition is a
waitlist and a rules page. Entries can wait. The hook is in.

The site lives at **https://omadesign.app**. The old GitHub Pages URL sends you
there.

Install is one line. ARM64 and x86_64. Home directory. MIT.

```sh
curl -fsSL https://omadesign.app/install | sh
```

This is still a young native Linux studio. Layout is frames, stacks and
constraints — not Figma import. Sync is last-write-wins, not a CRDT. Clerk and
Convex are wired for when the keys land. The work is in the file.
