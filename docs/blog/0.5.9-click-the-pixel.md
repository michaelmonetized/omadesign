# Click the pixel you mean

Omadesign 0.5.9 is the build that passed QA on 24 September 2026.

## The eyedropper leaves the window

Press I. A loupe takes the screen. Click any pixel you can see, including
another window. The color lands in the fill. Escape comes back to the canvas.
Press I again for another screen pixel.

## The selection and the cutout

Alt subtracts from a pixel selection. Shift still adds. Dilate and erode stay
on a hard cutout instead of pegging the machine and dying.

## You're in

Welcome links open the browser and bring that window forward. When cloud
sign-in finishes, the dialog stays up and says you're in, with the account on
the next line. The welcome row and the File menu keep that line.

## Filters on vectors

Midnight Duotone runs on a page of vectors. Omadesign bakes what you see into
a layer named Filtered image and duotones that. Alpha stays. Undo removes the
layer.

Click the open end of a live pen path and the forward handle drops to zero.
The incoming handle stays, so the next segment can leave a sharp corner.

## Install

```sh
curl -fsSL https://omadesign.app/install | sh
```

Portable ARM64 and x86_64 packages are on the release page. An update leaves
an already installed plugin in place.
