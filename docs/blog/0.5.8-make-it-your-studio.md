# Make it your studio

Omadesign 0.5.8 adds Lua plugins and fixes the details that were getting in the
way of editing.

## A steadier welcome

The welcome screen uses the corrected transparent logo, 25% larger, against a
dark background. Its browser panels and creation buttons fade from the lighter
theme color into the background. Segmented buttons use gradients, the utility
links use Phosphor icons, and project folders have a squarer rounded outline.

The title bar stays visible, so open-document thumbnails stay in place when you
start working. Its menu uses the Omadesign wordmark. The filter icon has no button
background: hover turns it blue; an active filter turns it red. The template
chooser opens at its final width and stays there as the pointer moves into it.

## Keep editing the paths

Alt-dragging a corner-radius handle changes all corners in a path. Shift-select
several corners, then drag one selected corner’s radius handle to change that set.

Repeated unions and subtractions can create several contours inside one object.
Those contours now convert into editable compound paths, keeping holes intact.
Double-click with Select or Node to edit the nodes. Moves, handles, insertion,
deletion and breaking a contour work across the compound shape and undo normally.

**View → Guides** now has separate **Lock all guides** and **Unlock all guides**
commands.

## Add your own tools

**Plugins → Manage plugins** installs Lua files, folders and `.omaplug` bundles.
The included Studio starter has twelve actions: a pixel filter, shadow effect,
SVG icon, two brush presets, a canvas drawing tool, a pattern generator, an
editable gradient, a persistent color palette, a batch transform and two opt-in
behaviors.

Plugins run off the UI thread. A completed document action is one Undo step;
errors, cancellation and stale results do not partially change your work. You can
also process a folder of `.oma` documents from the command line into new files.

[Read the Lua API and contribution guide](/docs/plugins), download the starter,
and make something others can install. Lua and the examples ship inside the
Linux packages; no separate runtime is needed.

## Install

```sh
curl -fsSL https://omadesign.app/install | sh
```

Portable ARM64 and x86_64 packages are available from the release page. Existing
installed plugins are preserved when you update the app.
