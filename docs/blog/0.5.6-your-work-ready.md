# Your work, ready when you are

Omadesign 0.5.6 brings your files, projects and starting points together on a
new welcome screen. It follows your Omarchy colors and font, with your documents
on the left, creation actions in the center and brand projects on the right.

## Find the work you already have

Your Work finds every `.oma` under your home directory and sorts by modification
time. Thumbnails keep the document's natural proportions in a masonry browser
with up to three columns. Names appear on hover. Click to open, or Shift-click
to start selecting several. Filter by Vector, Raster, Layout, Photo or Motion;
recovered autosaves have their own tab.

Projects are ordinary directories containing `.omabrand`. No account or central
project database is needed. Open a project to see its subprojects first, then
all descendant `.oma` documents, newest modified first. Folder cards gather
asset previews inside their outline. Discovery skips hidden directories, Trash
and symlinks. Shared team projects appear separately when connected to cloud.

## Start with the right canvas

Vector and Layout open the template chooser; their file icons open blank size
setup. Raster opens size setup. Photo can enter the workspace, open a folder or
open one image. Project opens the brand editor. Motion remains available from
the editor once you have elements to animate.

Startup preferences still let you choose how to enter the app. Photo and Layout
retain their direct workspace entry, and Photo folder thumbnails stay usable
while previews load.

## Ask your agent

Learn with AI opens a question box and sends it to your configured Omarchy agent
with the Markdown documentation index. Create with agent takes a brief, points
the agent at the included Omadesign creation skill and starts in the project
you are browsing. If no agent is selected, the app explains how to choose one.

The skill covers editable `.oma` delivery, project brand assets, import limits
and checking the actual native render. Documentation and the skill are bundled
with the app for offline use:

```sh
omadesign --agent-docs manual
omadesign --agent-skill
```

## Join the conversation

[Join the Omadesign Discord](https://discord.gg/ejkZS2RBx) from the website or
welcome screen. Cloud registration, docs, contribution guidance, bug reports
and release notes are also within reach.

Both ARM64 and x86_64 Linux packages are built locally, include the creation
skill and docs, and install with the usual command:

```sh
curl -fsSL https://omadesign.app/install | sh
```

The installer verifies the archive's SHA-256 before installation. Existing
documents, projects and preferences remain in place.
