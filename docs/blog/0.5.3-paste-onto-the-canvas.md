# Paste it onto the canvas

Copy a screenshot. Switch to Omadesign. Press **Ctrl+V**.

The screenshot appears as a new pixel layer in the center of the canvas
you are looking at. The same works for an image copied from a browser or
an image file copied in your file manager.

Version **0.5.3** fixes that everyday operation. Plain text becomes an
editable text layer. SVG source and copied SVG files become vector
artwork. External content lands in the visible canvas center, even after
you pan or zoom.

Objects copied inside Omadesign keep their original positions when you
paste them, including onto another artboard. If you are editing text,
Paste inserts into that text.

Install or update:

```sh
curl -fsSL https://omadesign.app/install | sh
```

Relaunch Omadesign after updating. Run `omadesign --version` or
`~/.local/bin/omadesign --version` to check that you have **0.5.3**.

Linux downloads support ARM64 and x86_64 with a glibc 2.35 ceiling.
