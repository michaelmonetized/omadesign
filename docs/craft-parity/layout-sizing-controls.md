# Auto Layout sizing controls

Width sizing and Height sizing now use two bounded columns in the actual Auto Layout pane. Each existing label sits above its native Fixed/Hug/Fill combo, and the redundant Sizing heading is removed. The semantic controls, native arrow/Home/End behavior and typed layout/history route remain.

The original unbounded horizontal row placed the Height sizing combo beyond the 256-pixel dock: its actual rectangle was x1261–1361 while the dock clipped at x1193. The strict canonical Workspace regression at `9a01ac64` reproduced that failure before the production change. The corrected controls are checked in the same real dock at 256/288/420 pixels, including a window resize cycle and stable native owner IDs. Resizing alone must leave the document and history unchanged.

An actual desktop pointer-open/Escape/Down sequence then exposed a separate focus defect: the old combo opener did not request focus, so Down nudged the canvas. The existing shared native choice helper now requests focus on its actual clicked opener and restores that enabled opener only when its own shown popup closes with Escape. The first click-only correction still failed because egui clears focus at Escape begin-pass; its 2-pass/1-fail receipt is retained separately. That failure and its saved files are retained.

A separate native-key fixture checks Width Hug and Height Fill, retained focus, one history step per accepted choice, exact full-document Undo/Redo and native/image reopen. Disabled locked-layer controls remain nonmutating. The focused dock/history group passed 2/2 at `75f3aa8b`. The first pointer correction passed keyboard/history and the existing punctuation route but failed pointer Escape focus (2/1 at `878f73db`). The corrected owned-popup closure passed that exact failed route separately (1/1 at `f0237724`), then its genuine desktop build passed actual pointer/keyboard choices, one-step native Undo/Redo, a 1600×1000 → 1100×760 → 1600×1000 window cycle and cold-process reopen. Independent file inspection proved exact saved history and unchanged child/unrelated artwork. No combined final-head suite total is claimed. The private desktop workflow and independent saved-file inspection are recorded in `implementation/craft-layout-sizing-controls.json`; exact source receipts remain distinct.
