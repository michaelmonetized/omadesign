# Find and Replace

Edit > Find and Replace opens a native literal-text dialog. Ctrl+F opens it from the canvas; F3 finds the next matching visible, editable story and wraps. The dialog has Match case and Whole words options, selected-text or document scope, single-match replacement, Replace all and Select match. Find and replacement fields use the native text editor, including clipboard paste and paragraph returns.

The retained Vectorcraft reference is `b12a52f7249e0aa73f030587e05ed9ce0c73ab67`. Matching follows its nonoverlapping literal and per-scalar case rules. Matches do not cross character-style or retained SVG leaf boundaries. Whole-word tests use actual style-run boundaries and surrounding characters, so clipping a selected text range does not invent a word boundary. This is literal search, with no regular-expression or Find Font claim.

Document scope skips hidden and locked stories; selected text refuses stale or locked captured owners atomically. Linked frames are edited once per story. Captured document, selection, caret, revision and live-draft guards prevent applying a result to a different destination. Search and cancellation do not mutate the document or commit a live draft. Explicit Select match navigation uses the existing editor route. No-op replacements report their count while preserving history and redo.

Accepted edits use the existing typed Type command and ordinary history. Replacement content maps character spans, paragraph styles, untouched manual kerning and retained SVG text through the original ranges. Paragraph insertion/deletion and intentionally empty text are supported. Each accepted object/document operation is one Undo; live text keeps its normal draft boundary. The shared text composer rebuilds geometry.

Native action buttons keep single-line labels and owner IDs as they wrap into rows. The dialog can grow when the match preview appears and scrolls within short windows. All colors derive from the theme. No persistent search settings, model fields, dependencies, schema, public version or release action are added.
