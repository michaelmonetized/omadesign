# IDML publishing exchange

Open `.idml` through File → Open, a drop, or `--inspect`. Export through the Export dialog's **IDML · publishing** format or `--convert book.oma --output book.idml`. Save imported work as `.oma` before making changes. Conversion notes remain in the native project.

The reader creates editable artboards, vector paths, text frames and placed pixel layers. A story's full Unicode source lives in its first frame; reciprocal native frame links flow it across pages. Paragraph and character style names survive text insertion and deletion. Named style inheritance resolves font face, point size, tracking, leading, baseline shift, horizontal/vertical scale, no-break, paragraph alignment and hyphenation. Point sizes within a story use native character scaling. Source style definitions remain in standard IDML resources.

Top, left, bottom and right bleed, facing-page preference, page sides, master assignments and original master XML survive native save/reopen and IDML export. Masters appear as locked preview artwork on their assigned pages. Their original source is exported once. Master stories, referenced source layer definitions and package-owned image bytes are retained separately through native save/reopen. Export includes those exact owned image bytes at their original package paths. Master images loaded through the safe source-folder reader are embedded as standard Contents in the retained master XML, keeping the original URI, so they survive export to another folder. Master editing and page-item overrides are unsupported: editing or deleting a locked preview after unlocking it, while its page remains assigned to a master, causes IDML export to stop with a clear error, protecting that edit in `.oma`.

Linked PNG/JPEG/TIFF and other supported raster images become editable placed pixel layers. Source visibility and lock state survive raster decoding and native reopen; inherited previews remain locked. Export embeds current image pixels while retaining the original link URI. Missing links retain a visible frame and URI and produce a conversion note. Open reads links only from the package or the source document's folder and its descendants; it never fetches network URLs or reads files outside that folder. Keep the source and its Links folder together when first opening the IDML. No source asset is overwritten or moved.

Tables, footnotes, endnotes, notes, tracked changes, hyperlinks, text variables and XML stories produce explicit import notes. Table and note contents are omitted rather than flattened into the story. This is an exchange subset, not universal InDesign parity. Multicolumn frames become one column. Rotated/sheared text frames become their axis-aligned bounds; placed-image transforms/crops are fitted to the frame. Mixed text colors, complex swatches, unsupported paragraph formatting, group appearances, live effects and masks can differ; the reader/writer reports these limits. Font files are not embedded in IDML. Uninstalled fonts display a system fallback. Named definitions retain their source font request.

Thread chains are validated before story content is moved into their head; follower frames carry metadata without story buffers. A shared 256 MiB allowance counts owned text/style capacities, retained master data and decoded image buffers, and reserves space for the shared layout cache before reflow. This guards import allocations; it is not a process-wide renderer or font-cache memory limit.

The package reader limits input and expanded bytes to 256 MiB, each ZIP part to 32 MiB, entries to 4096, pages to 1024, native items to 16384, decoded images to 256 MiB and XML nodes per part to 200,000. It rejects duplicate/unsafe ZIP paths, missing included parts, cyclic style inheritance, broken/mismatched frame links and cyclic threads. Export writes the stored first `mimetype`, `META-INF/container.xml`, `designmap.xml`, standard resources, spreads, masters and stories. There is no private native-document sidecar.

The independent fixture is authored by `scripts/idml-fixture.mjs`. Focused tests import it, edit a Unicode story, save/reopen `.oma` and exercise both export routes. `scripts/check-idml.mjs OUTPUT.idml` reads ZIP records independently in Node, checks XML with libxml2, and checks page/story/master counts, IDs/references, bleed and image/link contents. For the master dependency regression, add `--master-source SOURCE.idml --native REOPENED.oma` to verify master layer references and compare exact owned payload hashes across source, native project and exported ZIP. For a source-folder-only master image, also pass `--master-image IMAGE --unavailable-source ORIGINAL_SOURCE_FOLDER`; the checker verifies inline bytes against the image and confirms the original folder is unavailable. These checks establish software/package behavior; they do not establish InDesign's native rendering or a physical print result.
