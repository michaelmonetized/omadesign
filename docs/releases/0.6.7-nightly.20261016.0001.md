# Omadesign 0.6.7-nightly.20261016.0001

Keep native pixels, type and motion editable through save, reopen and supported exports.

This nightly adds native 16-bit and float image storage, RGB/CMYK profiles, editable Photoshop type and placed-source descriptors. The display cache stays separate from the authoritative samples. Supported TIFF and PSD output keeps depth and profiles; unsupported precision reductions return an error.

Keyboard editing now reaches more existing controls, with named fields, visible errors and consistent focus. Accepted field edits share the document's Undo history. Grid tracks, explicit placement, baseline alignment and named component properties survive save/reopen; mixed stack edits preserve unrelated values on the other selected frames.

Motion adds expressions, Hold/Bezier keys, compositions and a 3D scene. Live retains current and historical native pixels, fonts and SVG resources through removal and Undo. Capability negotiation refuses documents an older client cannot preserve. Advanced Layout 28 remains unavailable in Live protocol 3.

PDF keeps supported gradients, patterns and text editable, including embedded fonts and logical Unicode. IDML preserves supported threaded multipage type, styles, master assets and affine frames. Native Affinity and Illustrator imports retain original source bytes and report unsupported structures.

Photo retains the original linear RAW samples. Native Design placement uses float pixels and the destination's actual profile and rendering intent. PNG16 and TIFF16 remain developed output, not rewritten camera RAW files. Memory admission covers initialized buffers and retained output ownership; large jobs can still refuse safely when resources are insufficient.

The bounded float compositor supports analytic paths, centered strokes, supported gradients, geometric frame clips and unit-interval bitmap masks. Full float SVG filters, patterns, appearance isolation and other unsupported paint combinations remain unfinished and refuse explicitly. PDF and OpenRaster do not silently reduce native documents.

Download the matching nightly installer from the [release assets](https://github.com/michaelmonetized/omadesign/releases/tag/v0.6.7-nightly.20261016.0001). Its default installation uses a separate **Omadesign Nightly** launcher and settings directory. The existing release remains available.

Build, test, package and checksum identities accompany the release in `verification.json`. Historical and current checks retain their own source revisions. Software checks do not establish physical display accuracy, tablet behavior, hosted multi-user acceptance, Adobe/InDesign compatibility or qualification of every RAW camera and compression mode. The accepted 0.5.0 human-QA evidence remains preserved.
