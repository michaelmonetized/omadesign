# Omadesign 0.5.6 release validation

Status: preparing the stable release. Build, artifact, installation and production
verification evidence will be recorded here before completion.

## Scope

- Three-column welcome screen with recursive local `.oma` discovery, natural-aspect
  masonry thumbnails, mode filtering, recovery, selection and brand-project navigation.
- Project discovery through `.omabrand`, nested project previews, and shared-team
  visibility only for an authenticated account with shared projects.
- Template and blank-size actions, Photo folder/image entry, and brand-editor creation.
- Omarchy default-agent prompts for learning and creating, self-hosted Markdown
  documentation, version-matched offline docs and the bundled creation skill.
- Discord links in the native app and website; stable 0.5.6 metadata, update notes
  and checksum-verifying ARM64/x86_64 installer support.
- Existing workspace, native chooser, Photo gallery, editing, privacy and updater
  work carried forward from the local nightly source tree.

User-facing changes: [release notes](../blog/0.5.6-your-work-ready.md).
Interaction agreement: [welcome screen](../welcome-screen.md).

## Website and packaging preparation

- Website TypeScript checking and a local Vercel production prebuild passed.
- The production output contains stable 0.5.6 Markdown documentation, creation
  skill and a six-file SHA-256 manifest. All generated hashes match the source
  documents, and the served installer matches `scripts/install-remote.sh` exactly.
- Local browser checks loaded the 0.5.6 article and home page, confirmed both
  architecture download links identify v0.5.6, and verified the Discord and skill
  destinations. No browser page errors or horizontal overflow were observed at
  1280px or 390px. Production auth environment was supplied to the local server;
  this is not a new cloud collaboration test.
- All release/installer scripts pass shell syntax checks. The creation skill
  passed its frontmatter/scaffold validator. Packages include physical Markdown
  and skill files in addition to the binary's embedded copies.
- The final website TypeScript check and production prebuild passed after the
  manual update. Generated documentation hashes match all six current sources.
  The AI workflow guide and downloadable kit consistently describe `.oma` as
  versioned structured JSON; the kit's 18 artwork files were preserved byte for
  byte, and all six native examples parse as JSON.

## Release policy

No desktop compute, caches or build artifacts are delegated to hosted runners.
