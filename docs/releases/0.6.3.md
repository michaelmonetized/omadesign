# Omadesign 0.6.3 release validation

Validated locally on 2026-10-01 for [release PR #190](https://github.com/michaelmonetized/omadesign/pull/190). This release implements the nine-item workspace roadmap: motion scrubbing, modifier selection and background opening, file/project menus, drag-to-move and Alt-drag-to-copy, personal templates, a dedicated Typography sidebar, icon tabs, and the centered rainbow mode group.

## Native checks

- **987 library tests passed, 0 failed, 8 ignored**; the final all-target check also passed. Ignored tests require optional external fixtures or explicitly requested workloads.
- **16 native WGPU acceptance checkpoints passed**, using real production UI code, egui pointer/key events, and disposable on-disk documents. These exercise selection, Return/Alt-click background opening, hover scrubbing, copy/move/clone/Trash, reusable templates, project creation, Typography, sidebar icons, Welcome, and Agent. Moving an open document rebases its tab; template reuse opens an unsaved editable copy.
- The motion preview changes 3,892 pixels in the measured thumbnail region between the left and right hover positions. The source document remains unchanged in the library regression.
- File-operation tests cover collision avoidance, all three new document modes, source retention on failure, same-filesystem moves, and cross-filesystem moves with hidden assets and symlinks. Photo paths and undo journals follow project moves.
- Credits were regenerated: 417 dependencies and 243 full license/notice texts. The Cargo.lock fingerprint matches.

The [validation receipt](../qa/release-0.6.3/validation.json), [full test log](../qa/release-0.6.3/tests-release.log), [native checkpoints](../qa/release-0.6.3/native/result.json), and screenshots retain the evidence. Production code was frozen at `01b26ce1`; subsequent code changes only correct test fixtures and acceptance-harness targeting.

## Actual-machine validation

Fresh profiles and isolated install prefixes were used; application workloads ran with networking disabled. ARM64 passes ten package checks. AMD/amdgpu and Intel/i915 each pass all 13 package checks, including install-byte parity, version, conversion, save/reopen, and native rendering. All three produce the same 1200×900 PNG, SHA-256 `3cdce7cb10fc90dff5db55b2fc50ad0f7ba28eebc51ec5deab0071c4d3fe08df`.

The x86 model checks use retained, pinned supplemental helpers to verify the installed runtime and bundled model compatibility. They are not a claim of current production UI inference. The separate settled-window captures use the unmodified installed production app. Native screenshots were inspected at full resolution; menu and Inspector regions match across repeat captures, with at most two intensity levels of GPU antialiasing difference between AMD and Intel. Task applications and private compositors exited; existing remote installs remain unchanged.
