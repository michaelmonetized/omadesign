# 0.5.5-nightly.1 workspace release validation

Status: release preparation. Build, packaging, installation and publication
results will be recorded here after verification.

## Source and scope

Version **0.5.5-nightly.1**, tag `v0.5.5-nightly.1`, builds on 0.5.4 with the
workspace changes in the [changelog](../../CHANGELOG.md). It is a nightly
prerelease; the website's stable release remains **0.5.4**.

- File choosers run on a worker so the native event loop remains available to
  answer compositor pings while the chooser is focused. The chooser belongs to
  the document that opened it; cancellation or a changed destination does not
  apply a result. An untitled document's pending close/navigation resumes only
  after saving succeeds.
- Photo folders populate a full-width thumbnail library without a filename
  picker. Thumbnails include saved development settings, crop and rotation;
  opened photos reflect current edits. Folder changes cancel previous preview
  work. The existing 10,000-file folder limit remains; retained preview pixels
  are bounded and only visible cards keep GPU textures. Opening an image still
  loads its full source for editing.
- Photo and Layout start without an artboard. Saved Layout documents explicitly
  preserve an artboardless workspace; legacy documents retain their fallback
  artboard behavior. Older releases do not preserve the new artboardless state.
- Startup mode and start-screen page preferences persist independently,
  including remembering the last mode and the last New, Templates, Recent or
  Recovered page.
- Centered icon-only mode tabs use the requested Phosphor glyphs. Document
  previews are 64 × 64 logical pixels in the outermost left rail. The tools sit
  directly beside the canvas, with Photo's library or Layout's hierarchy between
  the document rail and tools. Arrange, Align and horizontal/vertical flip
  controls are in the right inspector.

## Build policy

Desktop tests, compilation and packaging run locally. `scripts/release.sh`
produces ARM64 and x86_64 portable packages and checks the glibc ceiling and
native dependencies. GitHub hosts source and release artifacts; Blacksmith is
reserved for website CI. A queued or unexecuted job is not a passed check.
