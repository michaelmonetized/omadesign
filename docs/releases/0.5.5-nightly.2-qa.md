## Delivered behavior

- Clicking **omadesign** opens a single dialog with **Config | Update | About | Docs**. About embeds `media/logo-4-refined.svg`, shows the branded alpha/nightly name and full semantic version, and links to an available update. Docs opens `https://omadesign.app/docs/`.
- Config edits existing startup preferences, UI font/size, ruler and shortcut display, default guide locking, update checks, anonymous usage consent and photo-provider keys. Unknown JSON options are preserved. Preferences save atomically under `$XDG_CONFIG_HOME/omadesign` or `~/.config/omadesign`. The existing nightly launcher retains its isolated config/data directories.
- Design eyedropper samples the active raster layer. Alt draws shapes from the center; Shift constrains their proportions. Strokes support widths above 64, inside/center/outside placement and persistent controls.
- Guides start locked and have lock/unlock/clear-all actions. Pixel Ctrl-click creates an outline selection that can mask another layer/object. Layer context menus offer Delete and Mask from item, followed by a target click.
- Groups select, move, align and duplicate as units; hidden/locked children retain their offsets. A lone selected group aligns to the artboard; mixed selections treat each group as one item. Double-click isolates a member until selection changes. Duplicated group hierarchy and motion tracks are remapped, with copies placed in place.
- Pixel Ctrl+D deselects an existing pixel selection; Super+D duplicates in place. Native Linux input now retains the physical Super modifier independently from Ctrl.
- Ellipses use four smooth cubic anchors. Handle length uses the standard circle approximation, approximately 0.55228475 times each radius: half the full width/height would bulge beyond a circle. Anchor radius controls are available with the Node tool and hidden with Select.
- Documents using object masks or inside/outside stroke alignment are written as format 6 so older readers cannot silently discard these features. Ordinary documents retain format 5. SVG carries the masks/placement; PDF uses raster fallback where needed; unsupported Lottie masks/alignment fail explicitly.

## Updates and recovery

Update checks use semantic versions and require architecture-matching packages with checksum assets. Stable builds ignore prereleases. Installation fetches the official HTTPS installer using curl, checks download/installer failures and verifies the installed version. Nightly installation keeps the existing isolated prefix and updates its launcher.

After installation, the app waits for edits and background work, then snapshots open tabs, unsaved documents, pixel selections, original photo pixels (including 16-bit RAW), photo adjustments, palette drafts and workspace state into local recovery storage. A successful snapshot precedes exec of the new binary; failure leaves the current workspace open. Recovery is loaded completely before replacing live state. Undo history is not carried across restart.

Fresh-process restore is checked below. The entire public download-and-update cycle is not claimed as exercised: this local nightly has not been published as a newer public release.

## Telemetry and production

Usage is opt-in and off by default. The app sends allowlisted counters, version, architecture and calendar periods. There is no persistent visitor/install ID, document content, paths, typed text, stack trace or raw error payload. Opt-out clears queued counters. Activity totals approximate participating installations, not unique people.

`/api/telemetry` validates bounded, closed-schema requests, stores only aggregates in Convex and forwards fixed error/crash categories to the supplied Sentry project through the server. The app never sends a client IP/user context to Sentry. Hosting providers still receive network connection metadata as disclosed in `/docs/privacy/`.
