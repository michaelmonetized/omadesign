# 0.5.4 integrated graphics and Layout release validation

Status: released on 2026-09-20. Integrated source, final portable artifacts, native runtime checks, public downloads and the production website are verified.

## Source and scope

0.5.4 starts from published 0.5.3 source `6e7fd237d499166c3ea83032f12a67634130fc25` and integrates the Design Tools preview plus the previously separate native Layout work. Native external clipboard paste, Omarchy clipboard-history support and cloud sharing/review remain present.

The merge keeps the 0.5.3 clipboard modules and transports Layout variables, remaps component links, and preserves the placement of copied subtrees extracted from rotated frames. Pixel selection tint now follows rotated images. Regression tests cover these combined workflows.

Full user-facing changes and limits are in the [release notes](../blog/0.5.4-more-control-on-the-canvas.md) and [manual](../MANUAL.md).

## Build policy

Desktop tests, builds and packaging run locally. `scripts/release.sh` builds ARM64 and x86_64 with Zig and rejects glibc requirements above 2.35 or external native codec dependencies. GitHub coordinates source/release hosting; Blacksmith is used only for website CI. Queued hosted jobs do not count as executed checks.
