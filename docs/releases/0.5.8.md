Status: published as stable/latest, deployed to production, and installed from the
public installer on the local ARM64 machine.

Release: [v0.5.8](https://github.com/michaelmonetized/omadesign/releases/tag/v0.5.8),
tagged at `cb0f86b72b2583fc4437b933eb2b47b53ab96f14`.

## Delivered

- Preserve the supplied transparent logo/wordmark SVGs and project-folder SVG.
  Enlarge the welcome logo 25%, use dark surroundings with lighter gradient
  panels/buttons, replace segmented dividers with gradients, use Phosphor utility
  icons and square rounded project folders.
- Keep the title bar visible on Welcome, use its SVG wordmark menu, remove duplicate
  Open/Preferences links, and render the filter without a background (blue hover,
  red active). The template chooser now opens at its stable final width.
- Alt-drag a corner-radius handle to edit all corners; selected-corner radius
  edits work as a set. Repeated Boolean results retain independently editable
  contours and holes, including node movement, handles, insertion, deletion,
  breaking, native save/reopen, Undo/Redo and SVG export.
- Add View → Guides → Lock all guides / Unlock all guides.
- Embed Lua 5.4.9 and API 1: native plugin manager, typed parameters, background
  execution/cancellation, one-step document Undo, canvas gestures, opt-in events,
  bounded local asset access, folder/file/ZIP installation and document batch CLI.
  Ship twelve starter actions, offline/public docs, contribution instructions and
  Lua/Phosphor licenses. Existing installed plugin modifications survive updates.
- Publish transparent site branding and 0.5.8 release/docs/download links. Existing
  homepage films remain unchanged.
