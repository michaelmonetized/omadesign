# Studio starter

Install this folder with **Plugins → Manage plugins → Install folder**, or:

```sh
omadesign --install-plugin /path/to/studio-starter
```

The source is a working, MIT-licensed example of every API 1 contribution category.
Select objects for Effects/Gradients/Batch. Choose a pixel layer for Filters and
Brushes. Activate Ribbon then drag on the canvas. Patterns and Icons create native
editable objects. Swatches persist in the personal palette library. Behaviors run
only when their checkbox is enabled in the plugin manager.

See `docs/plugins.md` for the API, packaging, contribution and batch-processing guide.
