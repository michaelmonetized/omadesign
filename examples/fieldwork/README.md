# Fieldwork

An original example kit for a small studio with a warm, outdoorsy character: coral, sage, ochre, deep green ink, and uncoated paper. All six graphics were drawn for this example; no stock assets or external downloads are included.

- **Fieldwork** — the core six colors, from coral and sage to ink and paper.
- **Morning light** — soft peach, straw, pale green, and cool sky accents.
- **After rain** — deeper greens with quiet stone and clay neutrals.

`.omacolors` is a portable JSON palette library. `.omabrand/brand.json` names the asset bank; the neighboring `marks`, `illustrations`, and `patterns` folders contain six editable SVG files. Keep these hidden files and folders when copying the kit. Save a document in this folder or a subfolder to discover the kit automatically, or select `.omabrand` in the Brand library sidebar. Assets can be dragged onto an artboard; palette swatches apply the chosen color.

The SVGs intentionally use plain paths with explicit fills and strokes. They do not require fonts, linked images, scripts, filters, CSS, or transforms. This small SVG subset matches omadesign’s native importer and keeps the thumbnails faithful and the shapes editable.

The artwork is covered by this repository’s MIT license. Adapt the colors, combine the marks, or replace the illustrations to make a kit of your own.
